# Luach Or — Support

The support page for **Luach Or**, a Jewish calendar, zmanim and blessings
reference for iPhone.

Live at <https://dilyagu22.github.io/LuachSupport/>

The privacy policy is a separate repository:
<https://dilyagu22.github.io/LuachPrivacy/>

## About this page

A single static `index.html`. No fonts, scripts, images or trackers are
fetched — everything, including the sky gradient and its stars, is CSS. That is
the same promise the app makes about itself.

The source of truth is `design/support-page/index.html` in the app repository;
this repo is the deployment target. Edit it there, then copy it here.
